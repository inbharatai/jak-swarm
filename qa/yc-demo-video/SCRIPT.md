# JAK Swarm YC Demo Video Script

Length: about 95 seconds.

1. JAK Swarm is the closed-loop AI operating layer for company execution.
2. It turns scattered artifacts into an evidence graph.
3. It detects drift between customer intent, decisions, tasks, specs, and code.
4. It routes work through an agent cockpit.
5. Risky actions pause for approval.
6. Every step leaves audit evidence.
7. The landing page promises tiered access to core and specialist agents.
8. The workspace exposes those roles as selectable runtime chips.
9. A leadership-roundtable command produces role-specific workflow evidence in local E2E.
10. Builder / vibe coding is a real dashboard surface.
11. A user can create a project and submit an app-building prompt.
12. Local E2E proves generated project files and a ready builder state.
13. This is a beta foundation today. The next milestone is live connector sync and hosted production validation.
